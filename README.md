# EventSchool - School Event Management Platform

A modern, responsive, frontend-only school event management system built with HTML5, CSS3, and Vanilla JavaScript. Designed specifically for schools to plan, organize, manage, and coordinate campus events.

## Features

- **Event Discovery & Filtering**: Search through school events in real-time, filter by category (Academic, Cultural, Sports, Workshops, Parent-Teacher Meets, Celebrations) and status.
- **Event Creation & Details Modal**: Full frontend form for creating new school events and detailed modals showcasing venue, schedule, and capacity.
- **Participant Registrations & Check-In**: Register students, teachers, parents, and guest speakers with a working local check-in/attendance status toggle.
- **Resource Management**: Track equipment, venues, and materials assigned to each school event.
- **Volunteer Coordination**: Assign student and staff volunteers to specific event roles and shifts.
- **Budget Tracking**: Monitor event expenses, grants, and income allocations.
- **Photo Gallery & Lightbox**: Responsive photo gallery showcasing school memories with an interactive lightbox viewer.
- **Reports Export**: Export event listings, attendance records, and budget reports directly to CSV format.
- **Role-Based Views**: Toggle between Admin, Coordinator, and Volunteer roles.

---

## Technology Stack

- **HTML5**: Semantic document structure.
- **CSS3**: Custom layouts, responsive grid, flexible components, and the warm orange/cream color palette.
- **Vanilla JavaScript**: DOM manipulation, interactive filters, modal triggers, local state management, and CSV export.
- **Icons & Fonts**: Font Awesome & Google Fonts (Plus Jakarta Sans).
